# local-songs — vos fichiers MIDI personnels

Déposez ici vos fichiers `.mid` / `.midi` (par exemple des exports iReal Pro).
L'application les détecte automatiquement (rechargez la page) et les propose dans l'onglet **Chansons**.

- Ce dossier est **ignoré par git** : vos fichiers ne sont jamais envoyés sur GitHub
  (les morceaux sont protégés par le droit d'auteur). Seul ce README est versionné.
- Nommez le fichier avec le titre du morceau, par exemple `Blue Bossa.mid` :
  le nom sert à le relier à la grille d'accords de votre bibliothèque iReal.
